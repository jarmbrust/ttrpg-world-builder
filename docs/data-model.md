# Data Model

## 1. Prisma schema (conceptual)

> Auth tables (`User`, `Session`, `Account`, `Verification`) are generated by **Better Auth** and
> merged into the Prisma schema (`npx @better-auth/cli generate`). `User` is extended with
> `platformRole` and `canCreateWorlds`. The generator/provider block should follow Prisma 7's
> current docs at implementation time.

```prisma
// --- Platform ---

enum PlatformRole {
  USER
  ADMIN
}

model User {
  id              String       @id
  name            String
  email           String       @unique
  emailVerified   Boolean      @default(false)
  image           String?
  platformRole    PlatformRole @default(USER)
  canCreateWorlds Boolean      @default(false) // admin-granted "approved GM"
  createdAt       DateTime     @default(now())
  updatedAt       DateTime     @updatedAt

  ownedWorlds     World[]            @relation("WorldOwner")
  memberships     Membership[]
  requests        WorldJoinRequest[]
  characters      Character[]        @relation("CharacterOwner")
  authored        Article[]          @relation("ArticleAuthor")
  edited          Article[]          @relation("ArticleEditor")
  uploads         Image[]
}

// --- Tenancy ---

model World {
  id         String   @id @default(cuid())
  slug       String   @unique          // ttrpgworldbuilder.com/w/[slug]
  name       String
  tagline    String                    // public 1–2 sentence blurb
  ownerId    String                    // the GM (primary authority)
  owner      User     @relation("WorldOwner", fields: [ownerId], references: [id])
  quotaBytes Int      @default(20971520) // 20 MB of text
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt

  memberships Membership[]
  requests    WorldJoinRequest[]
  articles    Article[]
  characters  Character[]
  tags        Tag[]
  images      Image[]
}

enum WorldRole {
  GM
  PLAYER
}

model Membership {
  id       String    @id @default(cuid())
  userId   String
  worldId  String
  role     WorldRole
  readOnly Boolean   @default(false)
  joinedAt DateTime  @default(now())
  user     User      @relation(fields: [userId], references: [id])
  world    World     @relation(fields: [worldId], references: [id])

  @@unique([userId, worldId])
  @@index([worldId, role])
}

enum RequestStatus {
  PENDING
  APPROVED
  DECLINED
}

model WorldJoinRequest {
  id              String        @id @default(cuid())
  worldId         String
  requesterUserId String
  message         String
  status          RequestStatus @default(PENDING)
  createdAt       DateTime      @default(now())
  world           World         @relation(fields: [worldId], references: [id])
  requester       User          @relation(fields: [requesterUserId], references: [id])

  @@index([worldId, status])
}

// --- Content (world-scoped) ---

enum ArticleType {
  WORLD
  LOCATION
  FACTION
  DEITY
  HISTORY
  HOUSE_RULE
  RECAP
}

enum Tier {
  PUBLIC
  PLAYER
  GM
}

enum ArticleStatus {
  DRAFT
  PUBLISHED
}

model Article {
  id           String        @id @default(cuid())
  worldId      String
  world        World         @relation(fields: [worldId], references: [id])
  slug         String
  title        String
  excerpt      String?
  body         String        // Markdown
  type         ArticleType
  tier         Tier          @default(GM)
  status       ArticleStatus @default(DRAFT)
  order        Int           @default(0)

  parentId     String?
  parent       Article?      @relation("ArticleTree", fields: [parentId], references: [id])
  children     Article[]     @relation("ArticleTree")

  tags         Tag[]
  links        ArticleLink[] @relation("ArticleSource")
  linkedBy     ArticleLink[] @relation("ArticleTarget")

  coverImageId String?
  coverImage   Image?        @relation("ArticleCover", fields: [coverImageId], references: [id])

  revealedAt   DateTime?
  createdById  String
  createdBy    User          @relation("ArticleAuthor", fields: [createdById], references: [id])
  updatedById  String?
  updatedBy    User?         @relation("ArticleEditor", fields: [updatedById], references: [id])
  createdAt    DateTime      @default(now())
  updatedAt    DateTime      @updatedAt

  @@unique([worldId, slug])
  @@index([worldId, type, tier])
  @@index([worldId, type, order])
}

// Explicit join for wiki-style cross-links (within one world).
model ArticleLink {
  articleId String
  relatedId String
  article   Article @relation("ArticleSource", fields: [articleId], references: [id])
  related   Article @relation("ArticleTarget", fields: [relatedId], references: [id])

  @@id([articleId, relatedId])
}

model Tag {
  id       String    @id @default(cuid())
  worldId  String
  world    World     @relation(fields: [worldId], references: [id])
  name     String
  articles Article[]

  @@unique([worldId, name])
}

// --- Characters (PC + NPC) ---

enum CharacterKind {
  PC
  NPC
}

model Character {
  id          String        @id @default(cuid())
  worldId     String
  world       World         @relation(fields: [worldId], references: [id])
  kind        CharacterKind
  userId      String?       // PC → owning player; NPC → null (GM-authored)
  user        User?         @relation("CharacterOwner", fields: [userId], references: [id])
  name        String
  class       String
  level       String        // free text ("5", "5th", "CR 3")
  ancestry    String
  description String
  background  String
  status      String        // current status ("Alive", "Deceased", …)
  imageId     String?
  image       Image?        @relation("CharacterPortrait", fields: [imageId], references: [id])
  updates     CharacterUpdate[]
  createdAt   DateTime      @default(now())
  updatedAt   DateTime      @updatedAt

  @@index([worldId, userId])
  @@index([worldId, kind])
}

// The character's "log" — short appended entries.
model CharacterUpdate {
  id          String    @id @default(cuid())
  characterId String
  character   Character @relation(fields: [characterId], references: [id])
  text        String
  createdAt   DateTime  @default(now())
}

// --- Images ---

model Image {
  id           String   @id @default(cuid())
  worldId      String
  world        World    @relation(fields: [worldId], references: [id])
  publicId     String   @unique // Cloudinary public id
  altText      String?
  tier         Tier     @default(GM)
  uploadedById String
  uploadedBy   User     @relation(fields: [uploadedById], references: [id])
  createdAt    DateTime @default(now())

  articles     Article[]   @relation("ArticleCover")
  characters   Character[] @relation("CharacterPortrait")
}
```

## 2. Content types → sections

Articles are world-scoped and share `/{worldSlug}/wiki/[slug]`. Characters are a separate entity.

| Section | Source | Index route |
|---|---|---|
| World overview & cosmology | `ArticleType.WORLD` | `/w/[slug]/world` |
| Regions & locations | `ArticleType.LOCATION` | `/w/[slug]/locations` |
| Factions & organizations | `ArticleType.FACTION` | `/w/[slug]/factions` |
| Pantheon, gods & religion | `ArticleType.DEITY` | `/w/[slug]/pantheon` |
| History & timeline | `ArticleType.HISTORY` | `/w/[slug]/history` |
| House rules & homebrew | `ArticleType.HOUSE_RULE` | `/w/[slug]/house-rules` |
| Session recaps / adventure log | `ArticleType.RECAP` | `/w/[slug]/recaps` |
| Characters (PCs + NPCs) | `Character` (filter by `kind`) | `/w/[slug]/characters` |
| Maps | images | `/w/[slug]/maps` |

> NPCs and PCs are **one entity** (`Character`) with `kind`. There is no `NPC` article type.

## 4. Data flow notes

- **Read:** Server Component → `verifySession()` → `requireMembership(worldId)` → Prisma query
  **filtered by `worldId`** and the viewer's readable tiers → render Markdown with cross-link
  resolution.
- **Write (GM):** Server Action → `authorize(worldId, { write: true })` (GM and not read-only) →
  upsert `Article` → (on reveal) set `tier = PLAYER` and `revealedAt = now()`, then
  `revalidateTag('world:<id>:article:<slug>')`.
- **PC edit:** Server Action → `authorize(worldId, { write: true })` → assert
  `Character.userId === session.userId` (or the viewer is the GM) → update fields / append
  `CharacterUpdate`.
- **Access request:** Server Action → `authorize(null, { requireUser: true })` → create a
  `WorldJoinRequest`; the GM approves (creates a `Membership`) or declines.
- **Images:** upload → Cloudinary → store `publicId` + `worldId` + `tier` → serve via
  `GET /api/images/[id]` which checks the viewer's world membership + tier and returns a short-lived
  signed URL.

## 5. Access-control summary

See [Architecture §4](architecture.md#4-access-control-model) for the full matrix.

- **Platform** authority comes from `User.platformRole` (`USER` | `ADMIN`).
- **World** authority comes from `Membership` (`GM` | `PLAYER`) + `World.ownerId`, with an optional
  `readOnly` flag.
- **Read scope** is the viewer's role in that world (anon → `public`; `PLAYER` → `public`+`player`;
  `GM`/admin → all tiers).
- **Write access** requires the role's capability **and** `readOnly: false`.
- **Every query must filter by `worldId`** — the cardinal multi-tenant rule; centralize it in the
  DAL/`authorize()` so no route can leak across worlds.
- **Quotas:** a GM owns ≤ 3 worlds; a world's article text is capped by `World.quotaBytes`
  (`sum(octet_length(body))`).
- **Future:** co-GMs per world (relax the one-GM rule; `World.ownerId` stays "primary"), and a
  `hideFromOtherGms` flag on articles.
